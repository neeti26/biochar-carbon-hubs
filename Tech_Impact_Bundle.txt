1.3 CORE ALGORITHMS
-------------------

A. Input Validation & Clamping

function validateInput(value, min, max) {
    const parsed = parseFloat(value);
    if (isNaN(parsed)) return min;
    return Math.max(min, Math.min(max, parsed));
}

Ensures all user inputs fall within scientifically reasonable ranges:
• Waste per hub: 100-2000 tons/year
• Number of hubs: 1-10,000
• Yield factor: 0.3-0.9 (30-90%)
• CO₂ per ton: 1.5-4.0 tCO₂e/t
• Stability factor: 0.5-1.0 (50-100%)
• Jobs per hub: 5-50

B. Carbon Sequestration Calculation

function calculateMetrics(params) {
    const totalWaste = params.wastePerHub * params.numHubs;
    const biocharTons = totalWaste * params.yieldFactor;
    const co2RawTons = biocharTons * params.co2PerTon;
    const co2StableTons = co2RawTons * params.stabilityFactor;
    const jobsTotal = params.numHubs * params.jobsPerHub;
    
    return { totalWaste, biocharTons, co2StableTons, jobsTotal };
}

Implements exact formulas from MRV specification (see MRV_Method.txt Section 5).

C. Chart Data Optimization (Performance)

For hub counts >200, the chart downsamples data points to prevent browser lag:

const maxPoints = 200;
const step = numHubs > maxPoints ? Math.ceil(numHubs / maxPoints) : 1;

for (let i = step; i <= numHubs; i += step) {
    chartData.push(calculateCO2ForHubs(i));
}

Ensures smooth rendering even at 10,000 hubs (tested).

D. Number Formatting

function formatNumber(num) {
    if (num >= 1000000) {
        return (num / 1000000).toFixed(2) + 'M';
    } else if (num >= 1000) {
        return num.toLocaleString('en-US', { maximumFractionDigits: 0 });
    } else {
        return num.toLocaleString('en-US', { maximumFractionDigits: 1 });
    }
}

Provides readable KPI displays: 1,200 → "1,200"; 1,200,000 → "1.20M"

2.1 PROBLEM STATEMENT & CONTEXT
--------------------------------

India's Agricultural Waste Crisis:
• 500+ million tons generated annually (Ministry of Agriculture, 2023)
• 30-40% openly burned (especially rice/wheat straw)
• Major contributor to PM2.5 pollution in North India (Oct-Nov)
• Lost economic value: ₹50,000 crore/year potential

Carbon & Climate Impact:
• Open burning releases 100+ million tons CO₂e/year
• Short-lived climate pollutants (black carbon) exacerbate regional warming
• India's NDC commitment: Reduce emissions intensity 45% by 2030 (vs 2005 baseline)

Socioeconomic Gap:
• Rural unemployment: 8.5% (higher in agricultural off-season)
• Youth migration to cities seeking opportunities
• Lack of value-added processing infrastructure in villages


2.2 SOLUTION MECHANICS - HOW BIOCHAR HUBS WORK
-----------------------------------------------

Decentralized Hub Model:
• 5-10 km service radius per hub (covering ~50 farmers)
• Community-operated (cooperative or social enterprise)
• Small-scale pyrolysis units (500-2000 tons/year capacity)
• Low-tech appropriate technology (brick kilns, drum reactors, or small gasifiers)

Pyrolysis Process:
1. Collection: Farmers bring agricultural residue (paid per ton)
2. Pre-processing: Chopping, moisture reduction if needed
3. Pyrolysis: Heating to 400-600°C in low-oxygen environment
4. Output: Biochar (solid), syngas (burned for heat), bio-oil (optional)
5. Application: Biochar sold back to farmers or to market

Why Biochar Sequesters Carbon:
• Pyrolysis converts volatile biomass carbon to stable aromatic carbon
• Biochar half-life in soil: 1,000-10,000 years (vs 1-5 years for crop residue)
• Effectively "locks" atmospheric CO₂ underground permanently

2.8 RISK ANALYSIS & MITIGATION
-------------------------------

Risk 1: Feedstock Supply Variability
Mitigation: Multi-crop sourcing (rice, wheat, maize, sugarcane), storage buffers

Risk 2: Biochar Market Demand
Mitigation: Guaranteed off-take agreements with farmer cooperatives, carbon credits as 
backup revenue

Risk 3: Technology Failure
Mitigation: Simple, proven pyrolysis tech (not cutting-edge experimental), local repair 
capability

Risk 4: Carbon Credit Certification Delays
Mitigation: Start with domestic sales (biochar), pursue credits in parallel (not dependency)

Risk 5: Community Acceptance
Mitigation: Participatory design, cooperative ownership, profit-sharing model
